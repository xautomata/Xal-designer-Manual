# XAL Designer — Documentazione

Questo manuale descrive il **XAL Designer**, l'editor visuale utilizzato per progettare, configurare e pubblicare automi sulla piattaforma XAUTOMATA.

---

## Cosa troverai qui

Il manuale è organizzato in tre sezioni.

**Concepts** introduce il modello degli automi — cosa sono, come funzionano e come si relazionano alla piattaforma XAUTOMATA. Leggi questa sezione per prima se sei nuovo a XAL.

**XAL Designer** è la guida operativa all'editor. Spiega come aprire i file, creare e configurare stati e transizioni, gestire le variabili e pubblicare le modifiche su un sistema di controllo versione.

**XAL Reference** è il riferimento tecnico per il linguaggio XAL. Descrive il formato del file, tutti gli elementi disponibili e i loro attributi. Questa sezione è pensata per gli sviluppatori e il team di delivery di XAUTOMATA.

---

## Prima di iniziare

Il XAL Designer lavora con file `.xal` salvati in un repository Git (GitHub, GitLab o Bitbucket) o sul proprio computer locale. È necessario avere accesso ad almeno un repository contenente file XAL, oppure disporre di un file da caricare direttamente nel browser.

!!! note
    Alcune funzionalità descritte in questo manuale non sono ancora disponibili. Queste sono segnalate con un avviso **Coming soon** dove applicabile.
